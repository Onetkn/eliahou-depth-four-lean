# Symbolic counting for three left generators at cutoff 4m

Status: independently derived research notes, **not yet Lean verified and not
claimed novel**. The presentation cutoff may exceed the true conductor.
Author of the eventual research artifact: Zhengyi Liu; this note was drafted
with AI assistance.

## Candidate proposition

Let d and m be positive integers with m > 12d. Put a=m+d. Let a<b<4m
and assume b is not generated by m and a. For the presentation

    S = <m,a,b> union [4m,infinity)

there are exactly three left primitive elements, and its presentation-relative
Eliahou number E is nonnegative.

The proof below handles b >= 4m/3 by direct counting. The final elementary
sumset argument handles b<4m/3 as well, without requiring that 4m be the
true conductor. This latter range is already covered, for canonical cutoffs,
by Eliahou 2018, Theorem 7.1 / Corollary 7.2.

The condition m>12d is deliberately conservative; it keeps collision
arguments transparent. This yields an infinite subfamily of the small-gap
problem but is not a proof of Bacher Conjecture 2.7.

## Base counts

For T=<m,a>, all elements below 5m are sums of at most four generators.
For each degree n=0,...,4 the values are nm+jd, j=0,...,n. As m>4d,
these five degree blocks are disjoint. Consequently

    |T intersect [0,4m)| = 1+2+3+4 = 10,
    |T intersect [4m,5m)| = 5.

Write k=|S intersect [0,4m)| and s for the number of decomposable elements
of S in [4m,5m). A decomposition in this interval cannot use any element
at least 4m, since the least positive element is m. Thus s counts exactly
the values from <m,a,b> in this interval. Since ell=3 and q=4,

    E = 3k - 4s.

All representations below 5m use at most four generators. We count them
by the number of occurrences of b; collisions can only reduce the upper
bounds for s. For k, collisions must be accounted for explicitly.

## Case A: 4m/3 <= b < (3m-d)/2

In addition to the ten base left elements, the following nine elements
lie below 4m:

    b, b+m, b+a, b+2m, b+m+a, b+2a;
    2b, 2b+m, 2b+a.

They are all distinct and avoid the base elements. To see this, write
b=m+t. Here m/3 <= t < (m-d)/2, hence t>4d. The terms containing one b
lie in the usual degree blocks but have offsets t+jd greater than the
base offsets. The term 2b is strictly below 3m-d and above 8m/3, while
2b+m and 2b+a exceed 11m/3; these intervals exclude base elements because
m>12d. An equality between a one-b term and a two-b term would force
b=um+vd for u an integer and |v|<=2, which is impossible in this range.
Thus k=19.

The threshold interval contains at most five base elements, four one-b
elements, three two-b elements, and one three-b element. Four b's are too
large. Hence s<=13 and E>=57-52=5.

## Case B: (3m-d)/2 <= b < 3m/2

The six one-b left elements from Case A remain present. Exactly two
two-b left elements remain: 2b and 2b+m. The same separation arguments
give k=18. For threshold elements containing two b's, the only possibilities
are 2b+a and 2b+2m: indeed 2b+2m+d>=5m. Thus s<=5+4+2+1=12,
and E>=54-48=6. Endpoints are assigned using the displayed weak/strict
inequalities, so a value equal to 4m is counted in the threshold interval.

## Case C: 3m/2 <= b < 2m-2d

There are six one-b left elements. They avoid the base because t=b-m>4d
and t+2d<m. The additional left element 2b may coincide with one base
element but cannot coincide with a one-b element: such an equality would
force b=m+jd or b=2m+jd with the available nonnegative j. Therefore k>=16.

There are at most four one-b threshold elements, two two-b threshold
elements (2b+m and 2b+a), and one three-b threshold element (3b).
Together with the five base elements this gives s<=12 and E>=48-48=0.

For completeness, the uniform bound of four one-b threshold elements
can be checked without any enumeration. Set u=2m-b>0. Their underlying
base terms are precisely 2m+jd (0<=j<=2, jd>=u), or 3m+jd
(0<=j<=3, jd<u). The sum of these two counts is at most four.

## Case D: 2m-2d <= b < 2m

Put u=2m-b, so 0<u<=2d. There are at least four one-b left elements:
b,b+m,b+a,b+2m. Of these, only b+a can coincide with a base element,
and that happens only at u=d, where b+a=3m. The two-b element 2b is
also left and lies above 3m+3d since m>7d. It cannot coincide with a
one-b element: the only potentially close equation is 2b=b+2m, which
would force b=2m. Hence k>=10+4-1+1=14.

The preceding u-count gives exactly three possible one-b threshold
elements. There are at most two two-b threshold elements, and no three-b
elements because 3b>=6m-6d>5m. Thus s<=5+3+2=10 and E>=42-40=2.

## Case E: 2m <= b < 3m (only m>4d is needed)

The element b is a new left primitive. If b+a<4m, both b+m and b+a
are left, and at least one is new: a collision b+m=3m+jd can only occur
at b=2m+3d after excluding b in <m,a>, in which case b+a=3m+4d is new.
If b+a>=4m, then b+m<4m and b+m>=4m-d>3m+3d, so b+m is new.
It follows that k>=12.

At most three one-b elements occur in the threshold interval (the
potential spillover b+a replaces, rather than supplements, higher
two-base-generator terms), and at most one two-b element, namely 2b.
Thus s<=5+4=9 and E>=36-36=0.

More explicitly, put v=3m-b>0. The one-b threshold possibilities are
b+a when d>=v, and b+2m+jd (j=0,1,2) when jd<v. Their total number is
at most three. Terms with three b's are at least 6m.

## Case F: 3m <= b < 4m (only m>4d is needed)

Only b itself is new below the cutoff, so k=11. The only possible new
threshold decomposables are b+m and b+a; hence s<=7 and E>=5.

## Literature boundary and novelty warning

### Elementary completion for a<b<4m/3

Set t=b-m>d, and A={0,d,t}. Every degree-n sum of m,a,b is nm+nA,
where nA={id+jt: i,j>=0, i+j<=n}. For n=0,1,2,3 the degree blocks
are disjoint and below 4m, since nb<(n+1)m. Every threshold decomposable
has degree four, so s<=|4A|. Hence it suffices to show

    3*(|0A|+|A|+|2A|+|3A|) >= 4*|4A|.

This can be proved explicitly for three-element integer sets. Write
g=gcd(d,t), p=t/g, u=d/g, with p>u>=1 and gcd(p,u)=1. Two pairs
(i,j),(i',j') represent the same offset iff u(i-i')+p(j-j')=0.
Coprimality forces p to divide i-i', and then their difference is an
integer multiple of (p,-u). The domain of pairs is the triangle
T_n={(i,j):i,j>=0, i+j<=n}, of size (n+1)(n+2)/2. Therefore:

* p>=5: there are no collisions for n<=4, so the five cardinalities are
  (1,3,6,10,15), giving difference 0.
* p=4: there are no collisions for n<=3; at n=4 the only collision is
  (4,0) with (0,u). Thus the cardinalities are (1,3,6,10,14), giving
  difference 4.
* p=3: necessarily u=1 or u=2. At n=3 there is one collision,
  (0,u) with (3,0). At n=4 there are exactly three collision pairs:
  their lower-i endpoint has j>=u and i+j<=u+1, giving exactly
  (0,u),(1,u),(0,u+1). Adding (3,-u) gives the respective upper-i
  endpoints (3,0),(4,0),(3,1). These are distinct and disjoint from the
  lower endpoints, and no class has three points because two relation
  steps require an i difference of six. This proof applies to both
  u=1 and u=2; equivalently the two offset sets are reflections in 3g.
  Thus the cardinalities are (1,3,6,9,12), giving difference 9.
* p=2: necessarily u=1, and nA is the scaled interval {0,g,...,2ng}.
  The cardinalities are (1,3,5,7,9), giving difference 12.

These exhaust p>=2 and complete the symbolic proof of the candidate
proposition for all b. The low-b argument is an elementary special case
of an existing true-grading theorem, not a new result.

Eliahou, *Wilf's conjecture and Macaulay's theorem*, JEMS 20 (2018),
2105--2129, DOI 10.4171/JEMS/807, Theorem 7.1 proves E>=rho under true
grading. Corollary 7.2 applies when all left primitives lie in
[m, m+(m-rho)/(q-1)). At c=4m this covers b<4m/3. Source:
https://ems.press/content/serial-article-files/32312

An initial targeted search did not find a theorem explicitly covering all
the remaining cases, but this is not a novelty certification. General
profile results, especially profiles (2,1,0), (2,0,1), and (3,0,0), must be
checked before claiming a publishable new result. The known criterion
|L|<=12 already covers some cases of E/F, and true grading covers some
low-b instances. More precisely, Eliahou and Marin-Aragon, *On numerical
semigroups with at most 12 left elements*, arXiv:2006.01480v1,
Theorem 4.1, explicitly proves W0(S)>=0 when |L|<=12, not just W(S)>=0:
https://arxiv.org/html/2006.01480#S4
That statement uses the true conductor; a cutoff-relative transfer is
needed before treating a noncanonical presentation as covered by it.
This note must not be advertised as a new theorem until
that review and an independent proof audit have finished.

## Computational sanity check

An independent in-memory monomial calculation checked d=1,...,9,
m=12d+1,...,12d+70, all integer b in [ceil(4m/3),4m), excluding b already
generated by m,m+d. In 155,817 triples it found no negative value of
3k-4s. This is a sanity check only; the symbolic proof is the proposed
justification for unbounded parameters. No file or certificate was retained
for that exploratory calculation, so a release must rerun a recorded test.

## Additional derived lemma: inserting high primitives

This lemma was suggested independently by the parent research agent and
has not been checked for novelty. Let c>=3m and S0 have multiplicity m,
and assume explicitly that every integer >=c belongs to S0.
Choose t distinct missing elements B in [c-m,c), and set S=S0 union B.
This is additively closed: B+(S0 without 0) lies at or above c, and
B+B lies at or above c+m. Old left primitive elements remain primitive;
the new B elements are primitive because they were absent from S0.
Thus k'=k+t, ell'=ell+t. Put a0=|S0 intersect [m,2m)|. New threshold
decomposables must be in B+(S0 intersect [m,2m)), giving r'>=r-a0*t.
Consequently

    E(S)-E(S0) >= t*(k+ell-q*a0)+t^2.

For a base S0=<m,m+d>_{qm}, q>=3 and qd<m, the disjoint-degree count
gives k=q(q+1)/2, ell=a0=2 and E(S0)=0. Therefore

    E(S) >= t^2 + t*(q^2-3q+4)/2.

This includes arbitrary numbers of added high primitives and arbitrary
depth. The proof is an explicit cardinality argument; all cutoff-relative
semantics must be retained in formalization.
