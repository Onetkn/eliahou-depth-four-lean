# Depth four with two elements in the first multiplicity interval

Mathematical conclusion, 2026-11-26. This supersedes the restricted
d<=6, m>12d, c=4m argument. The proof is uniform and does not use enumeration.
It has received independent internal mathematical review and is now fully
Lean verified by Eliahou.DepthFour.depth_four_nonneg. The scoped originality
comparison is in literature-review.md. The finished manuscript is paper/main.tex;
this file preserves the earlier readable derivation using removal of C.

## Theorem and notation

Let S be a numerical semigroup of multiplicity m containing [c,infinity),
where 3m<c<=4m. Suppose S intersect [m,2m)={m,m+d}, with 0<d<m.
Then E_c(S)>=0. In particular E(S)>=0 if c is the actual conductor.

Write c=3m+h, 1<=h<=m, rho=m-h, and a=m+d. Let k count S below c
(including zero), ell count primitive elements below c, and s count
decomposable elements in [c,c+m). Then E_c=ell*k-4*s+rho.
All intervals below contain integers and exclude the right endpoint.

## 1. Remove final primitives

Remove the primitive elements C in [c-m,c), obtaining R. A sum of remaining
positive elements cannot equal a removed primitive, so R is closed and
still contains [c,infinity). No decomposition below c uses C, since every
positive summand is at least m. Thus removal creates no new left primitives.

Restoring u=|C| elements adds u left elements and u left primitives. A new
decomposition in [c,c+m) uses one element of C and another summand less
than 2m, hence either m or a. Two C elements sum to at least 2(c-m)>c+m.
At most 2u right primitives are destroyed. R contains the six distinct
left elements 0,m,a,2m,m+a,3m, and has at least two left primitives. Hence

    E_c(S)-E_c(R) >= u*(k_R+ell_R-8)+u^2 >= u^2.

It suffices to prove E_c(R)>=0; all subsequent counts refer to R.

## 2. Counting reduction and shift bounds

The remaining primitives other than m,a are precisely B=2m+J for some
J subset [0,h). Put t=|J|. J avoids 0,d and also 2d when 2d<m:
these offsets would give sums of two first-interval elements.

Let T be the monoid generated by m,a, let k0=|T intersect [0,c)|,
s0=|T intersect [c,c+m)|, and E0=2k0-4s0+rho. Every element in s0 is
decomposable. Below c, two B elements cannot occur in a representation.
Induction on the value expresses every left element through left primitives.
The additional left elements are B and the nonbase elements 3m+x where

    U=J union P,   P=(J+d) intersect [0,h).

Let v count those nonbase elements. Thus k=k0+t+v and ell=2+t.

Exactly-one-B representations in [c,c+m) can only be, for j in J,

    (2m+j)+a,          when j+d>=h;
    (2m+j)+2m+i*d,     when j+i*d<h, i=0,1,2.

The upper bound for the first line is automatic. Adding only m stays
below c; adding three first-interval primitives reaches 5m>=c+m.
Let w count the distinct values displayed. Two B elements contribute at
most t(t+1)/2 values; any further primitive makes the sum too large.
Consequently s<=s0+w+t(t+1)/2, giving

    E_c(R) >= E0+(k0+2)t+(t+2)(v-t)-4w.                (1)

The following shift estimates will be used.

* Always w<=3t. When j+d>=h only the i=0 low value and the first-line
  value survive; otherwise there are at most three low values.
* If 2d>=h, w<=2t: i=2 never survives, and i=1 and the first line exclude
  each other.
* Put beta=|P\J|, so 0<=beta<=t. The low offset union
  (J+{0,d,2d}) intersect [0,h) has size at most t+2beta.
  A new second-shift element x outside J union P maps injectively to
  x-d in P\J. The first-line values contribute at most t more; hence
  w<=2t+2beta.
* If P subset J, applying this shift closure twice shows that the low
  offset union equals J, and w<=2t.

## 3. Case 2d<m

The six base elements below 3m are 0,m,a,2m,m+a,2a. The base offsets in
[3m,c) are {0,d,2d,3d} intersect [0,h). Hence:

| Range | k0 | s0 upper bound | E0 lower bound |
|---|---:|---:|---:|
| h<=d | 7 | 4 | rho-2 |
| d<h<=2d | 8 | 4 | rho |
| 2d<h<=3d | 9 | 4 | rho+2 |
| 3d<h | 10 | 5 | rho |

For the threshold bound, base values there must be 3m+i*d (i=1,2,3)
or 4m+i*d (i=0,1,2,3,4). For each i=1,2,3 at most one of the corresponding
two values lies in an interval of length m. The i=0 value contributes one;
the i=4 value occurs only if h>4d. Collisions can only decrease the count.

J avoids 0,d,2d; P avoids d,2d,3d. Thus U overlaps the base offsets only
possibly at 3d, from J itself.

In the first two rows v>=t and w<=2t, so (1) gives
E_c(R)>=E0+(k0-6)t>=0. In the first row rho=m-h>=m-d>=2.

In the third row v=t+beta and w<=2t+2beta. Equation (1) gives

    E_c(R) >= rho+2+3t+(t-6)beta.

This is nonnegative if t>=6. If 0<=t<=5, beta<=t gives the lower bound
rho+(t-1)(t-2), nonnegative for every integer t in that range.

In the fourth row, v>=t and w<=3t suffice. Otherwise the single possible
overlap forces v=t-1, 3d in J, and P subset J. Thus t>=1 and w<=2t,
and (1) gives E_c(R)>=rho+3t-2>0.

## 4. Case 2d=m

Here 2a=3m, k0=6 if h<=d and k0=7 if h>d, while s0=2 in both cases.
The high base offsets are {0,d} intersect [0,h), which U avoids.
Thus v>=t and w<=2t, so (1) gives

    E_c(R) >= 2k0-8+rho+(k0-6)t >= 0.

## 5. Case 2d>m

Put z=2d-m and r=3d-m, so 0<z<d<r. The five base elements below 3m are
0,m,a,2m,m+a. The high offsets are {0,z,d} intersect [0,h), whence

    k0=6+[h>z]+[h>d],    s0=3+[h>r].

Brackets are indicators. The threshold contains one of 2a and 2a+m,
one of 2m+a and 3m+a, the value 4m, and additionally 3a exactly when
h>r. These values are distinct in this case.

Only z can be an overlap of U with the high base offsets; it must come
from J. Set beta=|P\J| and e=[z in J]. Then v=t+beta-e and w<=2t, so

    E_c(R) >= E0+(k0-6)t+(t+2)(beta-e).                 (2)

In every row below E0>=0 and k0>=6. Thus beta>=e suffices. Otherwise
beta=0,e=1, so z in J and P subset J; this is the deficient case.

| Range | k0 | E0 | bound from (2) in the deficient case |
|---|---:|---:|---|
| h<=z | 6 | rho | impossible, since z not in J |
| z<h<=d | 7 | rho+2 | rho |
| d<h<=r | 8 | rho+4 | rho+t+2 |
| r<h | 8 | rho | rho+t-2 |

In the last row z in J and z+d=r<h force r in J by shift closure.
These are distinct, so t>=2. Thus the last bound is also nonnegative.
If r>=m, that row is empty. All boundary cases are included.

This proves E_c(R)>=0. Restoring C as in Section 1 proves the theorem.

## Scope

This covers every depth-four conductor, every gap d, and arbitrarily many
higher primitives under the exact first-interval-two condition. The interval
is the unshifted [m,2m), not a conductor-shifted Apery layer. The argument
does not treat three or more first-interval elements or depth greater than
four, and does not settle the full small-gap conjecture.

The complete manuscript and formalization are now included in the repository.
The manuscript uses an equivalent direct count of C to match the Lean proof.
Lack of a matching search result alone does not establish originality; see
the explicit comparison and limitations in literature-review.md.
